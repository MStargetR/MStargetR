# Calculate Percent RSD for QC Samples

Calculate Percent RSD for QC Samples

## Usage

``` r
bc_calculate_rsd(data, qc_label, metabolite_cols)
```

## Arguments

- data:

  A data.frame of sample data.

- qc_label:

  Character identifying QC samples.

- metabolite_cols:

  Character vector of metabolite column names.

## Value

Named numeric vector of percent RSD values.

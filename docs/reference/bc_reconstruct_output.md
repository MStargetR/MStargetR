# Reconstruct Output in Original Data Format

Reconstruct Output in Original Data Format

## Usage

``` r
bc_reconstruct_output(corrected_adjusted, original_data, metabolite_cols)
```

## Arguments

- corrected_adjusted:

  Tibble with corrected metabolite values.

- original_data:

  The original input data.frame.

- metabolite_cols:

  Character vector of metabolite column names.

## Value

Tibble matching the structure of the original data.

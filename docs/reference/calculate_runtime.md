# Calculate Runtime

This function calculates the runtime for the given section.

## Usage

``` r
calculate_runtime(master_list, section_name, previous_section_name)
```

## Arguments

- master_list:

  A list containing project details and script log information.

- section_name:

  A string representing the name of the current section.

- previous_section_name:

  A string representing the name of the previous section.

## Value

The updated `master_list` with the calculated runtime for the section.

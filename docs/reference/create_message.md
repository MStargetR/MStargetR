# Create Message

This function creates a message for the log.

## Usage

``` r
create_message(master_list, section_name, next_section_name)
```

## Arguments

- master_list:

  A list containing project details and script log information.

- section_name:

  A string representing the name of the current section.

- next_section_name:

  A string representing the name of the next section.

## Value

The updated `master_list` with the log message for the section.

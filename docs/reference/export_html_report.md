Export HTML Report This function exports the `master_list` data to an
HTML report using a predefined R Markdown template. It renders the
report and opens it in the default web browser.

## Usage

``` r
export_html_report(master_list)
```

## Arguments

- master_list:

  A list containing project details and data.

## Value

The updated `master_list` with the HTML report exported.

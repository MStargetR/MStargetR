# extract_timestamp

This function extracts the year from a timestamp string and converts it
to a numeric value.

## Usage

``` r
extract_timestamp(timestamp)
```

## Arguments

- timestamp:

  A string representing the timestamp.

## Value

A numeric value representing the year extracted from the timestamp.

## Examples

``` r
if (FALSE) { # \dontrun{
extract_timestamp("2025-06-17T13:31:58Z")
} # }
```

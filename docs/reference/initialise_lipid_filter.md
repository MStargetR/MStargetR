# Initialise lipid filter structure

This function initialses the structure for lipid filtering in the
`master_list`. It creates a list to store lipid missing values, a
summary data frame, and lists for project flags and failed lipids.

## Usage

``` r
initialise_lipid_filter(master_list)
```

## Arguments

- master_list:

  A list containing project details and data.

## Value

The updated `master_list` with initialised lipid filter structure.

# qcCheckR_import_PeakForgeR_reports

This function imports PeakForgeR reports from the project directory and
stores them in the master list.

## Usage

``` r
qcCheckR_import_PeakForgeR_reports(master_list)
```

## Arguments

- master_list:

  The master list object.

## Value

The updated master list object with PeakForgeR reports imported.

## Examples

``` r
if (FALSE) { # \dontrun{
master_list <- qcCheckR_import_PeakForgeR_reports(master_list)
} # }
```

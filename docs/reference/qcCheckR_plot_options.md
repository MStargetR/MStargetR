# Set Plot Options

Sets the plot color, fill, shape, and size options for the `master_list`
data based on sample types and QC type.

## Usage

``` r
qcCheckR_plot_options(master_list)
```

## Arguments

- master_list:

  A list containing project details and data.

## Value

The updated `master_list` with plot options set.

## Examples

``` r
if (FALSE) { # \dontrun{
master_list <- qcCheckR_plot_options(master_list)
} # }
```

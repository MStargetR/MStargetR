# Sort and Filter Data

This function sorts the run order data and filters it based on sample
types.

## Usage

``` r
sort_and_filter_data(run_order, transposed_data, sample_tags)
```

## Arguments

- run_order:

  A data frame containing the run order information.

- transposed_data:

  A data frame containing the transposed peak area data.

- sample_tags:

  A character vector of sample tags to filter by.

## Value

A data frame containing the sorted and filtered data.

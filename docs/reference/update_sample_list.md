# update_sample_list

This function updates the sample list for a given plate in the master
list.

## Usage

``` r
update_sample_list(master_list, idx_plate)
```

## Arguments

- master_list:

  A list containing project details and data.

- idx_plate:

  The index of the plate to update the sample list for.

## Value

The updated sample list for the specified plate.

## Examples

``` r
if (FALSE) { # \dontrun{
update_sample_list(master_list, idx_plate)
} # }
```

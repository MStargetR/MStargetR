# validate_master_list_project_directory This function validates the existence of the project directory specified in the master list.

validate_master_list_project_directory This function validates the
existence of the project directory specified in the master list.

## Usage

``` r
validate_master_list_project_directory(master_list)
```

## Arguments

- master_list:

  A list containing project details.

## Value

Stops execution if the project directory does not exist.

## Examples

``` r
if (FALSE) { # \dontrun{
validate_master_list_project_directory(master_list)
} # }
```

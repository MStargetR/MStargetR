# version_selector

ANPC specific helper function to reorder first version tried based on
jwist naming conventions.

## Usage

``` r
version_selector(master_list)
```

## Arguments

- master_list:

  A list containing project details and data.

## Value

Updated version list with the most probabilistic version first.

## Examples

``` r
if (FALSE) { # \dontrun{
version_selector(master_list)
} # }
```

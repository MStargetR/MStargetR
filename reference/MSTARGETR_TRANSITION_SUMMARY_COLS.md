# Columns selected from a non-unique transition table for the clash report

Shared by
[`transition_checkR()`](https://mstargetr.github.io/MStargetR/reference/transition_checkR.md)
so that the set of reported columns is defined in one place and can be
referenced by tests without duplicating the list.

## Usage

``` r
MSTARGETR_TRANSITION_SUMMARY_COLS
```

## Format

An object of class `character` of length 6.

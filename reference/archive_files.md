# Archive Files

This function moves a specified folder to the archive directory within
the project directory.

## Usage

``` r
archive_files(project_directory, folder_name)
```

## Arguments

- project_directory:

  The directory of the project.

- folder_name:

  The name of the folder to be archived.

## Value

Moves the specified folder to the archive directory.

## Examples

``` r
if (FALSE) { # \dontrun{
archive_files(project_directory, folder_name)
} # }
```

# create_summary_table

This function creates a summary table for a given plate in the master
list, including various project details.

## Usage

``` r
create_summary_table(master_list, plate_idx)
```

## Arguments

- master_list:

  A list containing project details and data.

- plate_idx:

  The index of the plate to create the summary table for.

## Value

A tibble containing the summary table with project details and their
values.

## Examples

``` r
if (FALSE) { # \dontrun{
create_summary_table(master_list, plate_idx)
} # }
```

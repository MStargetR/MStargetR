# delete_source_directory This function deletes the source directory after files have been moved.

delete_source_directory This function deletes the source directory after
files have been moved.

## Usage

``` r
delete_source_directory(source_dir)
```

## Arguments

- source_dir:

  Directory path for the folder to delete.

## Value

None. The function deletes the source directory.

## Examples

``` r
if (FALSE) { # \dontrun{
delete_source_directory(source_dir = "path/to/source")
} # }
```

# Find Matching PeakForgeR Report Name

This function finds the matching PeakForgeR report name based on the
plate ID.

## Usage

``` r
find_matching_report(report_list, plate_id)
```

## Arguments

- report_list:

  A list of PeakForgeR reports.

- plate_id:

  The ID of the plate to match.

## Value

The name of the matching report, or NULL if not found.

Get Common Control Metabolites This function retrieves the common
control metabolites across different SIL versions in the `master_list`.
It intersects the precursor names of control charts from each SIL
version's guide.

## Usage

``` r
get_common_control_metabolites(master_list)
```

## Arguments

- master_list:

  A list containing project details and templates.

## Value

A vector of common control metabolites.

# get_mzML_filelist

This function generates the mzML_filelist from FUNC_mzR

## Usage

``` r
get_mzML_filelist(FUNC_mzR)
```

## Arguments

- FUNC_mzR:

  List from master_list containing mzR object for each sample,
  mzR_header, mzR_chromatogram parsed internally.

## Value

A list containing mzML file information from plate.

## Examples

``` r
if (FALSE) { # \dontrun{
get_mzML_filelist(FUNC_mzR)
} # }
```

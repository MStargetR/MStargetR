# msConvertR_setup_project_directories

This function sets up project directories for each plate ID.

## Usage

``` r
msConvertR_setup_project_directories(output_directory, plateIDs)
```

## Arguments

- output_directory:

  Output directory for mzml files.

- plateIDs:

  vector of vendor files names being converted

## Value

None. The function sets up directories.

## Examples

``` r
if (FALSE) { # \dontrun{
msConvertR_setup_project_directories(output_directory, plateIDs)
} # }
```

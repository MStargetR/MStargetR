# qcCheckR_read_mrm_guides

This function reads MRM guides from user-supplied paths in the
mrm_template_list.

## Usage

``` r
qcCheckR_read_mrm_guides(master_list, mrm_template_list)
```

## Arguments

- master_list:

  The master list object.

- mrm_template_list:

  List of MRM guide file paths for tsv.

## Value

The updated master list object with MRM guides.

## Examples

``` r
if (FALSE) { # \dontrun{
master_list <- qcCheckR_read_mrm_guides(master_list, mrm_template_list)
} # }
```

# Summary Report

Generates a summary report for the `master_list` data, including metrics
for cohorts, matrix types, sample counts, lipid targets, SIL versions,
missing value filter flags, and RSD percentages.

## Usage

``` r
qcCheckR_summary_report(master_list)
```

## Arguments

- master_list:

  Master list generated by previous functions.

## Value

The updated `master_list` with the summary report.

## Examples

``` r
if (FALSE) { # \dontrun{
master_list <- qcCheckR_summary_report(master_list)
} # }
```

# save_plate_data

This function saves the master list data for a given plate to an RDA
file.

## Usage

``` r
save_plate_data(master_list, plate_idx)
```

## Arguments

- master_list:

  A list containing project details and data.

- plate_idx:

  The index of the plate to save the data for.

## Value

Saves the master list data to an RDA file in the specified project
directory.

## Examples

``` r
if (FALSE) { # \dontrun{
save_plate_data(master_list, plate_idx)
} # }
```

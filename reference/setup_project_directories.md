# setup_project_directories

This function sets up project directories for each plate ID.

## Usage

``` r
setup_project_directories(master_list)
```

## Arguments

- master_list:

  The master list object.

## Value

None. The function sets up directories.

## Examples

``` r
if (FALSE) { # \dontrun{
setup_project_directories(master_list)
} # }
```
